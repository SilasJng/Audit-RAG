## Check items

- List every external reader feeding totalAssets, totalBackingSigned, surplus, solvency, collateral ratio, or yield distribution
- For each reader, write the complete upstream response schema and classify every field as asset, liability, held/pending, price, metadata, or unknown
- Search for sibling borrow/debt/liability endpoints when the local reader name says supplied, collateral, balance, or TVL
- For every credited external asset field, identify the exact code path that subtracts matching liabilities before value-moving gates
- Add a negative-equity test: positive supply/collateral plus larger borrow/debt must make surplus or solvency non-positive
- Separate trusted-operator bad-parameter theories from contract-side gate failures caused by omitted liability fields
