## Summary

Silo Enterprise continuous audit 报告中，oracle factory calldata 的最后 32 bytes 被写入 deterministic salt；若 calldata 布局含 dynamic tail data，该写入会静默覆盖动态数据，部署出错误 oracle 配置。K2/Soroban 可类比检查 Address/BytesN/Vec 编码、salt、factory init args 与 oracle config 的边界。

## Broken invariants

- oracle factory initialization must preserve every semantic config field supplied by the caller
- deterministic deployment salts must not alias dynamic calldata tail data
