## Summary

Wise Lending 在 bad debt repay 路径中把未校验的 poolToken 传入 position token list 删除逻辑；当 token 不在用户数组中时，内部删除流程会清掉错误的 debt position，使用户可以免费抹除债务。

## Broken invariants

- repay or bad-debt helper code must only remove position entries that are actually owned by the position
- debt accounting must not be zeroed by passing a token that is absent from the authoritative position token list
