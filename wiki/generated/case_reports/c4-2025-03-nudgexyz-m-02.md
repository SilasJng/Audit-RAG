## Summary

The protocol grants SWAP_CALLER_ROLE to Li.Fi Executor so Executor can call handleReallocation after swaps. Because Executor.swapAndExecute is permissionless and can be instructed to call arbitrary target calldata, any user can make Executor call renounceRole on NudgeCampaignFactory for its own SWAP_CALLER_ROLE. This removes the authorized caller needed for subsequent reallocations. Admins can grant the role again, but the attacker can repeat the renounce flow, creating a persistent operational DoS.

## Broken invariants

- the configured swap executor should remain authorized unless changed by governance/admin
- permissionless users should not be able to disable protocol swap/reallocation flow
- role lifecycle for integration addresses should not be controllable by the integration contract via arbitrary external calldata
