## Summary

Users can claim rewards from a Merkle tree that’s being disputed. This can potentially lead to loss of funds since a malicious trusted EOA can claim funds from a malicious tree while it’s being disputed.

## Broken invariants

- reward and distribution accounting must preserve each participant’s accrued value under the root cause: Merkle claim logic does not block claims from a currently disputed tree, allowing funds to be claimed before dispute resolution
- reward and distribution accounting must preserve each participant’s accrued value across claims, transfers, and configuration changes
- state changes must remain internally consistent across all affected accounting buckets and external integrations
