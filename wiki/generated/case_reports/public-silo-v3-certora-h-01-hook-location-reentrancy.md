## Summary

Silo v2/v3 public audit notes that hook placement after checks but before final collateral/debt state updates can allow a legitimate hook configuration with reentrancy to free collateral tied to debt and drain a silo. K2 可借此检查 Soroban hook/callback、token receiver、flash-loan callback 或 compose-style 外部调用是否发生在不安全的中间状态。

## Broken invariants

- checks that bind debt to collateral must remain true across any external hook/callback before final state mutation
- value-moving hooks must not observe or mutate partially transitioned borrower state
