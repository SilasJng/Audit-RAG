## Summary

Stablecoin holders can receive wrongly calculated yield in the SavingsVest contract. Also, wrong vesting profit can be slashed when the protocol is under-collateralized.

## Broken invariants

- collateral management valuation must remain correct under the root cause: SavingsVest parameter updates occur before accruing pending interest, so yield and slash accounting use stale state
- oracle, TVL, and collateral valuation must use correctly scaled, fresh, and manipulation-resistant inputs
- reward and distribution accounting must preserve each participant’s accrued value across claims, transfers, and configuration changes
